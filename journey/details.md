# The 3-month roadmap

# Month 1: Python and core tools (the foundation)

Week 1: Set up your computer (VS Code, terminal, Git, GitHub). Python basics: variables, text, decisions, loops, functions.

Week 2: Lists, dictionaries, files, handling errors, modules, virtual environments. Mini projects.

Week 3: Classes and objects, testing your code, JSON, calling web APIs, debugging. Project: a command-line tool that uses a real API.

Week 4: SQL basics (databases) and your first backend with FastAPI. Project: a working REST API. Month 1 quiz and project demo.

# Month 2: Full stack (the web side)

Week 5: FastAPI deeper: Postgres database, user login, validation.

Week 6: HTML, CSS, and JavaScript. This is a new language, so we take it slowly.

Week 7: React and TypeScript basics. Build screens that talk to your API.

Week 8: Connect the frontend and backend, learn Docker basics, deploy online. Project: a full-stack app with a live link. Month 2 quiz and demo.

# Month 3: AI-native engineering and getting hired

Week 9: Using LLM APIs (including the Claude API): prompts, structured outputs, tool use. Build a small AI feature into your app.

Week 10: RAG: making an AI answer questions from your own documents (embeddings, vector databases). Start applying this week, about 5 applications a week.

Week 11: Agents that take actions, testing AI output, and working with AI coding tools like Claude Code. Project: your flagship AI app.

Week 12: Interview prep (data structures and algorithms, plus explaining your projects), polishing your portfolio, resume, LinkedIn, and mock interviews. Final quiz and demo.

Running in the background all 3 months: Data structures and algorithms practice, 45 minutes, 3 days a week (about 50 easy and medium problems total).

On Go: For internships, Python plus TypeScript is the stronger combination. I’d park Go until after Month 3. If you’re ahead of schedule, we can rewrite one small API in Go as a bonus.

## The weekly rhythm

Mon-Fri: Learn, practice, build, daily quiz.

Saturday: Morning for review and catching up, then the weekly quiz (about 1 hour), then rest of the day free.

Sunday: Full rest. No code. This is when my brain stores what I learned.

# Rules that will make me world-class

Struggle first, then ask. Try each problem for 15-20 minutes before asking or utilize an AI. Never paste a solution I don’t understand.

Type everything myself. No copy-paste while learning.

Commit my code to GitHub every day. It becomes my proof of work.

Use AI as a tutor, not a vending machine. Ask “why does this work?” often.
